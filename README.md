# Introduction
Simple mozilla extension to hide youtube shorts. 

Hides
- Shorts link in sidebar
- Shorts in homepage
- Shorts in search results

## Release History

### 1.1.1
- Fixed bug where extension required a click before working by requiring access to the YouTube domain.

### 1.1
- Added option to hide shorts in the YouTube subscriptions page.

### 1.0
- Toggle shorts visibility through the extension.
